🔐 Password Generator & Strength Checker

A simple Python program that generates strong passwords and checks the strength of any password. This project helps users create secure passwords and evaluate the security of existing ones.

Features

✅ Generate random passwords with letters, numbers, and special characters

✅ Check password strength (Weak, Medium, Strong)

✅ User can specify password length

✅ Interactive menu for easy use

Installation

Make sure you have Python 3.x installed on your computer.

Download or clone this repository.

git clone <repository-url>


Navigate to the project folder.

cd password-generator


Run the program:

python password_generator.py
